# Employee Management System
![Java](https://img.shields.io/badge/Java-17-orange)
![OOP](https://img.shields.io/badge/OOP-Object%20Oriented-blue)
![Git](https://img.shields.io/badge/Git-Version%20Control-red)
![GitHub](https://img.shields.io/badge/GitHub-Repository-black)

A Java console application developed to practice Object-Oriented Programming (OOP), Collections, and CRUD operations.

This project allows users to register, search, update, list, and remove employees through an interactive menu.

---

## Features

✔ Register employees

✔ List employees

✔ Search employees by ID

✔ Increase employee salary

✔ Remove employees

---

## How to Run

1. Clone this repository

```
git clone https://github.com/SEU-USUARIO/employee-management-system.git
```

2. Open the project in Eclipse

3. Run `Program.java`
